⚙️ Para el dueño de la cuenta (configura tu cobro Wompi)

El botón abre tu link de pago de Wompi (Bancolombia). Edita comprar.html (objeto PAGO arriba del script):

A
En tu panel de Wompi → Links de pago, crea un link para "5D Budgeting Pro" y pégalo en PAGO.link (ej: https://checkout.wompi.co/l/XXXXX).
B
Ajusta el precio mostrado en PAGO.precioCOP (la etiqueta; el cobro real lo define el link de Wompi).
C
Activación automática (SaaS): con Firebase configurado, al activar se marca pro:true en tu cuenta. Para que se active solo tras el pago confirmado, conecta el webhook/eventos de Wompi a una Cloud Function (ver functions/index.js y FIREBASE-SETUP.md).
D
Código de activación (opcional): define ACCESS_CODE para exigir un código que envías tras el pago. Vacío = activación por confianza (“Ya pagué”).

Nota: sin el webhook, la activación es por confianza (del lado del navegador). El webhook de Wompi es lo que la vuelve verificada de verdad.
